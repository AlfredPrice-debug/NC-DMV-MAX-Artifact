# NC DMV — Project Reference

Reference materials for the NC DMV **MAX implementation** project (Impact Makers). Includes a full capture of Arizona MVD's MAX system (the reference model) and a capture of North Carolina DMV's public site (the target agency).

## Arizona MVD — "MAX One Source" (reference system)
- **`knowledge.md`** — all 387 AZ One Source pages as one searchable text file. *Best AZ file to load into a Claude Project.*
- **`MVD_One_Source_ALL_pages.pdf`** — same content as one combined, bookmarked PDF.
- **`pdfs/`** — every AZ page as an individual PDF, mirroring the One Source site structure.
- **`artifact/max_navigator.html`** — the *MVD MAX Guide* dashboard ("Impact Makers Business Analyst Assistant"). Live: https://claude.ai/code/artifact/b5b86312-28f6-4706-adaf-ba1050e6e9d9
- **`reports/`** — AZ page index (CSV) + non-functional-links report.

## North Carolina DMV — ncdot.gov/dmv (target agency)
- **`nc-dmv-knowledge.md`** — 114 pages of NC DMV's public site (`/dmv/` section) as one searchable text file, grouped by section, with a broken-links list. Use for AZ ↔ NC comparison and scoping.
