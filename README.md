# NC DMV — MAX / One Source Reference

Complete reference capture of Arizona MVD's **MAX One Source** documentation, packaged for the Impact Makers team working on the NC DMV **MAX implementation**.

## Contents
- **`knowledge.md`** — all 387 captured pages as one searchable text file. **Best file to load into a Claude Project's knowledge.**
- **`MVD_One_Source_ALL_pages.pdf`** — the same content as one combined, bookmarked PDF (grouped by functional area) for reading.
- **`pdfs/`** — every captured page as an individual PDF, in folders mirroring the One Source site structure.
- **`artifact/max_navigator.html`** — the *MVD MAX Guide* dashboard ("Impact Makers Business Analyst Assistant"): ask a question about MAX, get step-by-step in-MAX walkthroughs across all areas, plus a printable "Meeting Mode" worksheet. Live version (Claude artifact): https://claude.ai/code/artifact/b5b86312-28f6-4706-adaf-ba1050e6e9d9
- **`reports/_INDEX_captured_pages.csv`** — index of every captured page (title + One Source path).
- **`reports/Non-Functional_Links.md`** — broken / unreachable One Source links, plotted by sidebar location, for the team to raise with the client.

## Source
Captured 2026-07-24 from `https://arizonadeptoftransportation.mcoutput.com/fullcopy1s/` (Arizona DOT MVD One Source). 387 pages captured; 51 links were non-functional (see report). Content © Arizona Department of Transportation; reference use for the NC DMV project.
