# NC DMV — MAX / One Source Reference

Reference materials for the NC DMV **MAX implementation** project, captured from Arizona MVD's "MAX One Source" documentation and packaged for the Impact Makers team.

## Contents
- **`MVD_One_Source_ALL_pages.pdf`** — combined, bookmarked PDF of all 387 captured One Source pages (the source of truth). Bookmarks are grouped by functional area.
- **`artifact/max_navigator.html`** — the *MVD MAX Guide* dashboard ("Impact Makers Business Analyst Assistant"). Ask a question about MAX and get step-by-step in-MAX walkthroughs across all One Source areas, plus a printable "Meeting Mode" worksheet. Live version (Claude artifact): https://claude.ai/code/artifact/b5b86312-28f6-4706-adaf-ba1050e6e9d9
- **`reports/_INDEX_captured_pages.csv`** — index of every captured page (title + One Source path).
- **`reports/Non-Functional_Links.md`** — broken / unreachable One Source links, plotted by sidebar location, for the team to raise with the client.
